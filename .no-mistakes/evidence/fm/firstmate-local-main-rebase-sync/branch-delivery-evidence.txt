## Config change

Applied to `C:\pc02-llm-server\bin\native-config.yaml` on PC02 (WSL path: `/mnt/c/pc02-llm-server/bin/native-config.yaml`):

Added flags to the `qwen3.8-27b-bartowski-q4_k_m` model entry:
- `-c 262144` (full context)
- `--cache-type-k q8_0` (KV cache K quantization)
- `--cache-type-v q8_0` (KV cache V quantization)
- `--no-kv-offload` (KV in system RAM, not VRAM)
- `--no-mmap` (avoid mmap page faults)
- `--spec-type draft-mtp` (multi-token prediction speculative decoding)
- `-ot "blk\.([89]|[1-5][0-9]|6[0-3])\.ffn_(gate|up|down)\.weight=CPU"` (offload FFN weights to CPU)

Backup: `native-config.yaml.bak-2026-09-07-qwen38-bartowski-opt-apply`

## Performance note

The optimized bartowski config runs slower than the dispatch entry:
- `qwen3.8-27b-dispatch`: 12.16 tok/s decode, 262.06 tok/s prompt processing
- `qwen3.8-27b-bartowski-q4_k_m` (new config): 1.84 tok/s decode, 44.61 tok/s prompt processing

The `--spec-type draft-mtp` and `-ot` offload flags appear to add overhead without the expected speed benefit on this hardware/system state. This may warrant further investigation if the captain wants to pursue MTP speculative decoding on PC02.
